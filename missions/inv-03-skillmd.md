Responde SOLO estas preguntas, con URL de fuente para cada una. Sé concreta y técnica:

1. ¿Cuál es la estructura EXACTA de un archivo SKILL.md? (campos obligatorios del frontmatter YAML, campos opcionales, formato del cuerpo)

2. ¿Cuáles son las rutas exactas donde cada motor busca skills?

   - OpenAI Codex CLI (Thot): ¿qué rutas?

4. ¿Qué carpetas opcionales puede tener una skill además del SKILL.md? (scripts/, references/, assets/ — para qué sirve cada una)

Para cada respuesta: URL de la fuente. Si no encontrás algo para un motor específico, decílo con honestidad — ese hueco también es un dato importante.
