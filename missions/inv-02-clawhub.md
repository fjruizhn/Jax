# INV-02 — ClawHub: el sistema de skills de OpenClaw

Investiga **ClawHub**, el marketplace/sistema de skills de OpenClaw. Queremos entender cómo distribuyen, instalan y organizan skills entre agentes, para diseñar lo nuestro.

Responde SOLO estas preguntas, con URL de fuente para cada una. Sé concreta:

1. ¿Qué es ClawHub exactamente y cómo funciona? (es un repo, una web, un registry tipo npm?)

2. ¿Cómo se instala una skill desde ClawHub a un agente? (comando, proceso, dónde quedan los archivos)

3. Vimos mención de "tres niveles de precedencia" de skills — ¿cuáles son y cómo funcionan? (ej. global vs proyecto vs usuario)

4. ¿Qué formato usan las skills de OpenClaw? ¿Es el estándar SKILL.md o uno propio?

5. ¿Cómo se publica o comparte una skill propia en ClawHub? (proceso de contribución)

Para cada respuesta: URL de la fuente. Si no encontrás algo, decílo con honestidad — no inventes.
