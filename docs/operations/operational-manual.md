# JAX Operational Manual

## Purpose and scope

This manual orients operators around Blocks 1–7. It is not authority and not a current deployment snapshot.

## Principles

Authority, implementation, runtime evidence, operations, adapters, generated presentation, history, and memory are separate layers. Use `jaxctl` and the [query guide](query-guide.md) for current facts.

## Authority, decision, execution, and evidence

Policy and verified authority artifacts govern. DecisionRecord is Block 5; governed execution is Block 6; WRITTEN, TESTED, and ENFORCED are bounded Block 7 evidence assertions, not permanent booleans.

## Operations

See service, database, trusted-file, diagnostic maps and the runbook index. Production execution is not enabled by this manual.

## Checklists and glossary

Before action, identify authority impact, query current state, use a supported runbook, verify outcome, and fail closed/escalate on integrity uncertainty. Memory is a locator only.
